# Tutorial de instalación y configuración

## Instalación en Android

Descargar e instalar la app

![](playstore.png)

[Delta Chat en el play store](https://play.google.com/store/apps/details?id=chat.delta)

## Configurar cuenta

Al iniciar deltachat veran un signo "+". Desde ahí se crea la cuenta

![](agregar_cta.png)

Seleccionan "crear perfil nuevo"

![](nombre.png)

completan el nombre y luego seleccionan "aceptar y crear perfil"

Listo! ya tienen la cuenta creada.
